## ☀️サービス概要
**okita!!** は、早起きを「自分の意思」ではなく 「つながり」と「仕組み」で実現するデュアルモード型の起床支援サービスです。
### 🧑‍🧒ソロモード
個人の習慣化支援。 起床時間設定 ＋ ワンタップで、無理なく継続できる習慣化をサポートします。

### 🧑‍🧑‍🧒‍🧒マルチモード（みんなで早起きチャレンジ）:
オープンな「約束」による共同起床。 掲示板で早起きチャレンジを公開-参加し、募集人数が揃うと即座にマルチが成立。メンバー全員での同時刻の起床証明を必須とすることで、寝坊しづらいプレッシャーや達成感を提供します。

## 📖サービス開発の背景
私は、目覚ましアプリをどれだけ工夫しても「スヌーズ → 二度寝」を繰り返してしまうタイプでした。
しかし、友人と「朝ジムに行こう」と約束した日は絶対に起きられる経験から、人は“自分のためには弱いが、他人との約束には強い”ということを実感しました。
そこで
- 一人でも続けられる仕組み
- 誰かと約束することで続けやすい仕組み
この２つを組み合わせた、強制力のあるサービスを作りたいと思い、okita!! を着想しました。
